# External Services and Data Sharing Review — Ritucast

## 1. Overview

This document reviews all external third-party services and APIs connected to Ritucast, auditing data transmission boundaries, privacy exposure risks, and redistribution compliance.

---

## 2. External Service Inventory & Transmission Review

Ritucast interacts with three external data sources:

| Service Provider | Role in Ritucast | Outbound Data Transmitted | Inbound Data Received | Privacy & Exposure Risk |
| :--- | :--- | :--- | :--- | :--- |
| **Open-Meteo Weather API** (`open-meteo.com`) | Numerical weather forecast feed | Upazila centroid latitude and longitude coordinates (`lat`, `lon`), timezone | 7-day hourly temperature, rainfall, humidity, wind, and ensemble spread | **None**: Centroid coordinates correspond to regional Upazila centers, not farm parcels. Zero user identifiers sent. |
| **NASA POWER Project** (`power.larc.nasa.gov`) | Historical agro-climatology & radiation | Regional geographic bounding box, date ranges, agro-climatology parameters | Daily solar radiation, max/min temperatures, precipitation | **None**: Broad regional queries. Zero user data transmitted. |
| **Copernicus Open Access Hub** (`dataspace.copernicus.eu`) | Sentinel-1 SAR backscatter & flood extents | Regional bounding box over Haor Basin testbeds | GRD radar backscatter scenes for water body mapping | **None**: Geospatial tile queries. Zero user data transmitted. |

---

## 3. Direct Browser Querying Prohibition (`DEC-09`)

- **Strict Architecture Policy**: The React client browser application has **zero direct connectivity** to NASA, Open-Meteo, or Copernicus.
- All requests flow exclusively through Ritucast's intermediate backend service.
- **Benefits**:
  1. Prevents exposing client IP addresses or location signals to external commercial third parties.
  2. Guarantees deterministic offline caching and eliminates upstream rate limit exhaustion.
  3. Insulates users from upstream API downtime or structural schema changes.

---

## 4. Third-Party Data Sharing & Commercial Prohibitions (`DEC-06`)

1. **No Data Broker Transmission**: Ritucast does not sell, lease, or transmit user query logs, geographic requests, or advisory reads to data brokers, agricultural input manufacturers, commercial banks, or insurance underwriters.
2. **No Advertising Networks**: Zero ad-tech SDKs or monetization trackers are installed.
3. **No Commercial Endorsements**: Agricultural recommendations generated by Ritucast are strictly generic (e.g., *"নলকূপের সেচ স্থগিত রাখুন"* or *"বোরো ধান ৮০% পেকে গেলে দ্রুত কর্তন করুন"*). The system is strictly barred from recommending branded fertilizers, commercial pesticides, or proprietary hybrid seeds (`DEC-06`).
